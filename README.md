# Todo App — Frontend React

Interface utilisateur pour la gestion de tâches.

## Technologies
- React 18
- TypeScript
- Tailwind CSS v4
- Axios

## Installation

```bash
git clone https://github.com/votre-username/todo-app-frontend.git
cd todo-app-frontend
npm install
npm run dev
```

## Fonctionnalités
- Inscription et connexion
- Créer, modifier, supprimer des tâches
- Filtrer par statut
- Routes protégées
